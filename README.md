# Awesome Investment Stack

A curated, opinionated list of professional open-source tools for quantitative investing,
grouped by the stage of the investment process they serve. Every entry is actively
maintained and widely used in industry or research.

## Contents
- [Research platforms](#research-platforms)
- [Backtesting & portfolio construction](#backtesting--portfolio-construction)

## Research platforms
| Project | Language | What it is for |
|---|---|---|
| [microsoft/qlib](https://github.com/microsoft/qlib) | Python | AI-oriented quant research platform: data, models, backtests |
| [QuantConnect/Lean](https://github.com/QuantConnect/Lean) | C# / Python | Institutional-grade event-driven research and live engine |
| [nautechsystems/nautilus_trader](https://github.com/nautechsystems/nautilus_trader) | Rust / Python | Deterministic, production-grade trading engine |

## Backtesting & portfolio construction
| Project | Language | What it is for |
|---|---|---|
| [polakowo/vectorbt](https://github.com/polakowo/vectorbt) | Python | Vectorised backtesting for large parameter sweeps |
| [kernc/backtesting.py](https://github.com/kernc/backtesting.py) | Python | Lightweight, readable strategy backtests |
| [PyPortfolio/PyPortfolioOpt](https://github.com/PyPortfolio/PyPortfolioOpt) | Python | Mean-variance, Black-Litterman, HRP optimisation |
| [dcajasn/Riskfolio-Lib](https://github.com/dcajasn/Riskfolio-Lib) | Python | Risk-parity and advanced risk-measure optimisation |
